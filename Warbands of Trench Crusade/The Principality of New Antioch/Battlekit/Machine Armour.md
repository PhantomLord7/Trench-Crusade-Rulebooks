# Machine Armour

*Сочетая редчайшие божественные металлические сплавы с новейшими технологиями New Antioch, machine armour превращает своего носителя в живой танк.*

## Profile

| Type | Range | Keywords |
|---|---|---|
| Armour | — | -3 INJURY MODIFIER |

**Stipulations:** ELITE & Mechanized Heavy Infantry only, Limit: 1 excluding Mechanized Heavy Infantry
**Cost:** 50 👑

## Special Rules

☩ **Bulky:** Размер base модели с Machine Armour меняется на **40 мм**, если он ещё не равен 40 мм или больше. Кроме того, модель с Machine Armour не может быть снаряжена Trench Shield, и её Charge Bonus составляет **D3"** вместо D6".

☩ **Standfast:** Когда модель с Machine Armour получает результат **Down** в Injury Roll, он считается результатом **Minor Hit**.
