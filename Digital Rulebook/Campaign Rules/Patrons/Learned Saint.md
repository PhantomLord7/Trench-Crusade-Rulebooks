# Learned Saint

> **Только Trench Pilgrims и New Antioch.**

*Твой **Patron** — великий учитель, такой как Святой Патрик, Святой Фома Аквинский или Святой Мефодий. Такие **Patrons** освещают пути планирования, науки, стратегии и организационных способностей.*

Наличие **Learned Saint** в качестве **Patron** позволяет тебе брать следующие **Skills**:

- ☩ **Favoured by God:** в конце каждой партии твой **Warband** получает дополнительно **1 ☼** за каждую модель с этим **Skill**, находящуюся на поле боя.
- ☩ **Healing Arts:** ты можешь перебросить результат на **Trauma Chart** (▶ см. [[#Trauma Step|Trauma Step]]) для модели с этим **Skill**.
- ☩ **Knowledge of Sciences:** лимит на один элемент **Battlekit** (за исключением **Glory Items**) увеличивается на **1**, если модель с этим **Skill** входит в состав **Warband**. Выбери, к какому **Battlekit** будет применён бонус, и запиши свой выбор в **roster**. В **Warband** может быть только одна модель с этим **Skill**.
- ☩ **Logistical Skills:** **Warband**, включающий модель с этим **Skill**, может увеличить любые лимиты на количество моделей, которое он может включать, **на 1** — при условии, что модель не имеет Keyword [[ELITE]], не установлена на базе **50 мм** или больше, и не является **Mercenary**. Например, если **Warband Entry** для модели в **Warband** имел лимит **0–2**, лимит будет увеличен до **0–3**. Если модель с этим **Skill** убита или иным образом удалена из **Warband**, модели сверх обычных лимитов можно сохранить, но новые модели сверх лимитов добавлять нельзя. В **Warband** может быть только **1 модель** с этим **Skill**.
- ☩ **Pennies from Heaven:** в конце каждой партии твой **Warband** получает дополнительно **D6×5 👑** за каждую модель с этим **Skill**, находящуюся на поле боя.
- ☩ **Walk with God:** выбери один **Skill** из любой **Skill Table**, доступной модели, включая любой **Exploration Skill**, и передай его этой модели.
