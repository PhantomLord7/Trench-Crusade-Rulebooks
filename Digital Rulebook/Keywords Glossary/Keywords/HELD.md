# HELD

**Тип:** Effect

Элемент **Battlekit** с этим **Keyword** требует одной руки для переноски и не может быть положен. Из-за этого модель с этим **Keyword** может быть оснащена или использовать только **1-Handed Weapon** или **Shield**. Она не может быть оснащена двумя **2-Handed Weapons**, или одновременно **Weapon** и **Shield** (даже если у **Shield** есть правило **Shield Combo**). Модель всё ещё может нести **Grenades**.
