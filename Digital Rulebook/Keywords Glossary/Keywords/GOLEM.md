# GOLEM

**Тип:** Effect

Модель с этим **Keyword** считает результат **Out of Action** из **Injury Roll Table** как **Down** — если только этот результат не вызван **Bloodbath Roll**. Кроме того, ты не можешь убирать **BLOOD MARKERS** с дружественной модели с этим **Keyword** (оппонент может тратить их как обычно). Наконец, модель с этим **Keyword** обладает **Keywords** [[NEGATE FEAR]] и [[NEGATE GAS]], но не может иметь **Keyword** [[TOUGH]].
