# +/- DICE

**Тип:** Effect

Кубики, прибавляемые к **Success Rolls** (▶ см. [[Core Rules#^SuccessRolls|Success Rolls]]). Если **Keyword** относится к **Weapon**, кубики прибавляются только к **Success Rolls** для атак, совершаемых этим оружием.
