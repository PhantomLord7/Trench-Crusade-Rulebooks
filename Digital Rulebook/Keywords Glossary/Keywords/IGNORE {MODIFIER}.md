# IGNORE [MODIFIER]

**Тип:** Effect

Игнорируй **Success Roll** или **Injury Roll** модификатор, который указан. Например, **Success Roll** для атаки, совершённой **Ranged Weapon** с Keyword **IGNORE COVER**, не будет затронут модификатором **-1 DICE** за цель в **Cover**.
