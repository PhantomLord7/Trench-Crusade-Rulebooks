# Red Banner

*Red Brigade несёт в бой залатанный красный штандарт, сшитый из пропитанного кровью плаща Saint Ernest. Ни один солдат Бригады не покинет битву, пока реет это святое знамя. Когда последнего выжившего Бригады отправляют в New Antioch, он забирает этот флаг с собой.*
